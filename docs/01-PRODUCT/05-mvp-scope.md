# 05 Mvp Scope
# MANNMITRA — MVP SCOPE

**Status:** Approved

---

# MVP OBJECTIVE

The MVP must demonstrate the complete MannMitra product philosophy
without attempting to implement every advanced feature.

The MVP should prove:

UNDERSTAND
→ PLAN
→ PREVENT
→ EXPERIENCE
→ REFLECT
→ CONNECT

---

# PHASE 1 — FOUNDATION

## Include

- authentication
- registration
- onboarding
- student profile
- dashboard
- navigation
- responsive design
- privacy foundation

---

# PHASE 2 — CORE MITRA

## Include

- AI chat
- basic context
- supportive responses
- task extraction
- planning assistance
- basic recommendations
- AI safety boundaries

---

# PHASE 3 — PLANNING

## Include

- tasks
- task priorities
- deadlines
- calendar
- academic workload
- basic AI-assisted planning

---

# PHASE 4 — WELLNESS

## Include

- stress check-in
- mood check-in
- basic wellness history
- basic analytics
- basic stress awareness

---

# PHASE 5 — COMMUNITY

## Include

- community feed
- anonymous identity
- posts
- comments
- reactions
- reporting
- blocking
- basic moderation
- senior stories

---

# PHASE 6 — REFLECTION

## Include

- reflection prompts
- personal reflections
- basic history

---

# PHASE 7 — SUPPORT

## Include where feasible for MVP:

- counsellor discovery
- counselling request
- trusted contact configuration
- safety entry point

---

# MVP SHOULD NOT OVERREACH

Do not delay the MVP by attempting to build every advanced capability.

Advanced capabilities can follow after the core loop is validated.

---

# MVP QUALITY REQUIREMENT

Every MVP feature must still meet production-quality expectations
for its scope.

The MVP is not permission to ignore:

- security
- privacy
- accessibility
- responsive design
- validation
- error handling
- AI safety
