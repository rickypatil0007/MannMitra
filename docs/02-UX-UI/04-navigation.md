# 04 Navigation
# MANNMITRA — NAVIGATION SYSTEM

---

# DESKTOP

Primary navigation should be persistent but visually quiet.

Recommended structure:

MANNMITRA

Home
Mitra
Planner
Wellness
Community
Support

----------------

Profile
Settings

---

# ACTIVE STATE

Active destination should use:

- subtle green accent
- soft green background
- clear text contrast

Do not use aggressive highlighting.

---

# MOBILE

Use bottom navigation.

Recommended:

Home
Mitra
Planner
Wellness
More

Use icons with labels.

Do not rely on icons alone.

---

# MORE MENU

Contains:

Community
Support
Profile
Settings
Privacy
Notifications

---

# BREADCRUMBS

Use only where necessary.

Do not add breadcrumbs to simple mobile experiences.

---

# BACK NAVIGATION

Back behavior must preserve user context.

Example:

Community Post
→ Post Detail
→ Back
→ return to previous scroll position.

---

# DEEP LINKS

Important pages should support direct navigation.

Sensitive data must never be exposed through unsafe URLs.

---

# NAVIGATION PRINCIPLE

Navigation should help users answer:

"Where am I?"

"Where can I go?"

"How do I get back?"

without visual clutter.
