# 05 Responsive Design
# MANNMITRA — RESPONSIVE DESIGN

---

# PRINCIPLE

MannMitra must be genuinely responsive.

Do not simply shrink desktop layouts.

---

# MOBILE

Primary width range:

320px–767px

Design priorities:

- single-column layouts
- large touch targets
- simplified navigation
- concise content
- sticky primary actions where useful
- bottom navigation

---

# TABLET

768px–1023px

Use:

- flexible grids
- two-column layouts where useful
- expanded navigation when space allows

---

# DESKTOP

1024px+

Use:

- multi-column layouts
- persistent navigation
- larger content areas
- contextual side panels where useful

---

# LARGE DESKTOP

1440px+

Do not stretch content indefinitely.

Use maximum content width.

Maintain whitespace.

---

# TOUCH TARGETS

Interactive controls should have a comfortable touch area.

Target approximately:

44px minimum interaction size.

---

# MOBILE TYPOGRAPHY

Do not simply scale desktop typography down.

Maintain readable hierarchy.

---

# MOBILE CARDS

Cards should not become excessively tall.

Prioritize content.

---

# MOBILE MODALS

Prefer:

- bottom sheets
- full-screen sheets

for complex mobile interactions.

---

# MOBILE FORMS

Forms should:

- use single-column layouts
- have clear labels
- minimize typing
- preserve entered data after validation errors

---

# RESPONSIVE PRINCIPLE

At every breakpoint ask:

What information is essential?

What can disappear?

What can move?

What can become contextual?
