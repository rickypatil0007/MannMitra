# Storage

## 1. Purpose
Defines how MannMitra handles unstructured binary data, specifically user avatars, uploaded attachments in support requests, and audio recordings for Voice Notes.

## 2. Scope
Covers the configuration, security, and usage of Supabase Storage buckets.

## 3. Buckets

### `avatars` (Public)
- **Purpose**: Profile pictures for community identity (if real-name is used) or counsellor profiles.
- **Access**: Publicly readable. Writable only by the authenticated owner.
- **Constraints**: Max size 2MB. Allowed MIME types: `image/jpeg`, `image/png`, `image/webp`.

### `voice_notes` (Private)
- **Purpose**: Highly sensitive audio recordings created by students for self-comfort (Feature 09) or visual-talking interactions.
- **Access**: Strictly private. Readable and writable ONLY by the owning student (`auth.uid()`).
- **Constraints**: Max size 10MB (approx 5-10 mins of compressed audio). Allowed MIME types: `audio/webm`, `audio/mp4`, `audio/mpeg`.

### `support_attachments` (Restricted)
- **Purpose**: Screenshots or documents uploaded by a student when submitting a support ticket to a counsellor.
- **Access**: Readable by the owning student and the assigned counsellor.

## 4. Security / Storage RLS
- Supabase Storage integrates directly with PostgreSQL RLS. Policies must be applied to the `storage.objects` table.
- Example for Voice Notes:
```sql
CREATE POLICY "Voice notes are entirely private" 
ON storage.objects FOR SELECT 
USING (bucket_id = 'voice_notes' AND auth.uid() = owner);
```

## 5. Content Delivery (CDN)
- Public buckets (`avatars`) utilize the Supabase Edge CDN for fast global loading.
- Private buckets (`voice_notes`) require a short-lived Signed URL generated by the backend API to stream the audio securely to the client, preventing URL guessing.

## 6. Edge Cases
- **Malicious Uploads**: The client-side UI restricts file types, but the Storage Bucket configuration MUST also enforce MIME type restrictions at the server level to prevent a user from uploading a malicious `.exe` or `.html` file.

## 7. Testing
- Attempt to generate a public URL for an object inside the `voice_notes` bucket and assert it fails.
