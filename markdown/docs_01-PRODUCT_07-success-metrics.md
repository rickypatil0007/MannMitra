# 07 Success Metrics
# MANNMITRA — SUCCESS METRICS

---

# 1. PRODUCT SUCCESS

MannMitra should measure whether it is providing meaningful support.

Primary outcomes:

- students successfully completing onboarding
- students returning for meaningful use
- students completing planned actions
- students using reflection
- students accessing appropriate support
- students reporting improved clarity
- students discovering useful resources

---

# 2. WELLNESS METRICS

Potential metrics:

- wellness check-in completion
- stress tracking consistency
- reflection completion
- perceived usefulness
- support discovery
- self-reported improvement

Metrics must not be interpreted as clinical outcomes unless validated
through appropriate research.

---

# 3. PLANNING METRICS

Measure:

- tasks created
- tasks completed
- deadlines managed
- planning sessions
- AI-assisted plans
- plan adjustments
- completion patterns

Avoid using productivity metrics to imply personal worth.

---

# 4. MITRA METRICS

Measure:

- meaningful conversations
- task extraction success
- recommendation usefulness
- planning usefulness
- user feedback
- response quality
- safety classification accuracy

Do not optimize Mitra purely for:

- number of messages
- session duration
- compulsive engagement

---

# 5. COMMUNITY METRICS

Measure:

- active contributors
- meaningful interactions
- helpful reactions
- moderation response time
- report resolution
- anonymous participation
- community retention

Avoid optimizing for controversy or excessive posting.

---

# 6. SUPPORT METRICS

Measure:

- counselling discovery
- counselling requests
- appointment completion
- trusted contact setup
- support resource discovery

---

# 7. SAFETY METRICS

Track:

- safety classifier performance
- false positives
- false negatives
- escalation reliability
- safety workflow completion
- unsafe AI response rate

Safety metrics must receive higher priority than engagement metrics.

---

# 8. PRIVACY METRICS

Monitor:

- unauthorized access attempts
- privacy incidents
- consent completion
- data deletion requests
- access-control violations

---

# 9. TECHNICAL METRICS

Track:

- page load performance
- API latency
- error rates
- availability
- database performance
- AI latency
- AI cost
- notification delivery
- failed jobs

---

# 10. ACCESSIBILITY METRICS

Track:

- accessibility defects
- keyboard navigation issues
- contrast failures
- screen-reader issues
- reduced-motion compatibility

---

# 11. NORTH STAR

The primary product question should be:

"Did MannMitra help the student understand, plan, connect, reflect,
or take a healthier next step?"

Not:

"Did the student spend more time inside the application?"
