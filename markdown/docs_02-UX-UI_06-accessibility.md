# 06 Accessibility
# MANNMITRA — ACCESSIBILITY

Target:

WCAG 2.2 AA

---

# KEYBOARD

All interactive elements must be keyboard accessible.

Focus order must follow logical reading order.

---

# FOCUS

Focus states must always be visible.

Never remove focus indicators without replacement.

---

# COLOR

Do not communicate meaning using color alone.

Example:

A warning should use:

icon
+
text
+
color

not color alone.

---

# CONTRAST

Normal text must maintain appropriate contrast.

Secondary text must remain readable.

---

# SCREEN READERS

Use semantic HTML.

Buttons must be buttons.

Links must be links.

Forms must have labels.

---

# ICONS

Decorative icons should be hidden from assistive technologies.

Meaningful icons require accessible labels.

---

# FORMS

Errors must be associated with their fields.

Error messages must explain how to fix the problem.

---

# MOTION

Support:

prefers-reduced-motion

When enabled:

- reduce animation
- remove unnecessary movement
- preserve functionality

---

# TEXT

Do not embed important text inside images.

Allow text scaling.

---

# TOUCH

Touch targets should be comfortably sized.

Avoid tiny controls.

---

# CHAT ACCESSIBILITY

AI chat must support:

- keyboard navigation
- screen readers
- readable message structure
- accessible composer
- clear loading state

---

# CHART ACCESSIBILITY

Charts must provide textual summaries.

Do not require visual interpretation alone.

---

# ACCESSIBILITY PRINCIPLE

Accessibility should feel native to the design rather than appearing
as an afterthought.
