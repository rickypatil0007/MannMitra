# 07 Motion Interaction
# MANNMITRA — MOTION & INTERACTION

---

# MOTION PHILOSOPHY

Motion should communicate:

- state
- hierarchy
- continuity
- feedback

Motion must not exist merely to impress.

---

# TIMING

Micro interaction:

120–180ms

Standard transition:

180–250ms

Large transition:

300–450ms

Avoid unnecessarily slow animations.

---

# EASING

Use smooth ease-out for entering elements.

Use smooth ease-in-out for state transitions.

Avoid exaggerated bounce effects.

---

# BUTTON INTERACTION

Hover:

slight surface change

Pressed:

subtle scale or tonal change

Focus:

clear accessible focus ring

---

# CARD INTERACTION

Cards should not dramatically jump or enlarge.

If interactive:

- subtle elevation
- slight border change
- subtle surface transition

---

# PAGE TRANSITIONS

Use subtle transitions only where they improve continuity.

Do not animate entire pages unnecessarily.

---

# CHAT

New AI responses may:

- fade in subtly
- stream naturally

Do not animate every word dramatically.

---

# LOADING

Use:

- skeletons
- subtle progress indicators
- streaming states

Avoid excessive spinners.

---

# SUCCESS

Success should be calm.

Example:

Task completed
→ subtle check
→ gentle state transition

Avoid confetti by default.

---

# ERROR

Errors should appear clearly but calmly.

Avoid flashing red animations.

---

# MODALS

Use:

- subtle backdrop
- slight elevation
- smooth entry

---

# REDUCED MOTION

When reduced motion is enabled:

- disable decorative animations
- reduce transitions
- preserve usability

---

# MOTION PRINCIPLE

If removing an animation does not reduce understanding,
remove the animation.
