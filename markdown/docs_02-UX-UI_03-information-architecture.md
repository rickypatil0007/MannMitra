# INFORMATION HIERARCHY

Primary navigation should contain only the highest-value destinations.

Secondary functionality should live inside the appropriate destination.

Do not expose every feature in the global navigation.

---

# MOBILE INFORMATION ARCHITECTURE

Primary bottom navigation:

Home
Mitra
Planner
Wellness
More

Community and Support may be accessible through More or contextual
navigation depending on the final screen design.

---

# IA PRINCIPLE

Organize around student goals rather than internal technical systems.

Students think:

"I need help."

"I need to plan."

"I feel stressed."

"I want to talk."

"I need someone."

They do not think:

"Open the AI orchestration system."
